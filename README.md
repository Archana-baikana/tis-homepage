
# Tula's International School — Homepage Redesign

A modern, responsive and animated homepage redesign for Tula's International School (TIS).

## 🚀 Project Overview

This project redesigns the Tula's International School homepage with a modern user experience while maintaining the school's core identity and content.

The goal was to create a visually engaging, responsive and conversion-focused landing page for students and parents.

## ✨ Features

- Modern responsive homepage
- Responsive navigation with mobile menu
- Animated hero section
- Scroll-triggered section animations
- Scroll progress indicator
- Interactive hover effects
- Academics and campus sections
- School statistics section
- Parent testimonials
- Admissions call-to-action
- Responsive design for mobile, tablet and desktop
- Production-ready build

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- JavaScript
- HTML5
- CSS3
